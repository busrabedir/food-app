## 🌿 Garden Of Flavor

Garden Of Flavor, vanilla JavaScript ve Bootstrap kullanılarak geliştirilmiş modern ve responsive bir yemek menü uygulamasıdır. Kullanıcılar menü öğelerini görüntüleyebilir, kategorilere göre filtreleme yapabilir ve ürün detay sayfasına dinamik olarak erişebilir. Proje, modüler JavaScript yapısı ve dinamik veri yönetimi üzerine odaklanmaktadır.

## ✨ Özellikler

- 📂 Local JSON dosyasından dinamik veri çekme
- 🔎 Kategoriye göre filtreleme
- 📄 URL parametresi ile dinamik ürün detay sayfası
- ⏳ Veri yüklenirken loading gösterimi
- ❌ Geçersiz ID durumunda Not Found ekranı
- 📱 Bootstrap ile tamamen responsive tasarım
- 🎨 Modern kart yapısı ve hover animasyonları

## 🛠️ Kullanılan Teknolojiler

- **HTML5**
- **CSS3**
- **JavaScript (ES6 Modules)**
- **Bootstrap 5**
- **Bootstrap Icons**
- **Fetch API**
